# 03 以钩引心：有意义的追读技术（Hook with Meaning）

> 成长向不是慢热的借口。番茄读者给你的耐心和给爽文的一样少。
> 原则：**保留爽文的节奏骨架，替换部分兑现物。**

## 一、爽点 → 觉点转化矩阵

不删爽点，而是让部分爽点"多走一步"：

| 爽点（hit 写法） | 觉点（growth 写法：多走一步） |
| :--- | :--- |
| 当众打脸 | 打脸之后，主角看见对方背后的处境，选择不再追击——读者先爽，再被触动 |
| 身份揭晓，众人震惊 | 身份揭晓后，主角发现最在意的人根本不在乎这个身份，只在乎他这个人 |
| 复仇成功 | 复仇成功的空洞；或在最后一刻选择交给法律，并为此付出代价 |
| 获得强大金手指 | 金手指第一次让他可以轻易伤害无辜者，他必须决定自己是什么样的人 |
| 暴富 | 钱到账那晚，他第一个想打电话的人已经不在了 |
| 被偏爱 | 主角第一次拒绝了不健康的偏爱，选择了自己 |

**比例建议（经验值）**：一卷中约 60-70% 的兑现保留爽点原样，30-40% 升级为觉点。全是觉点会失去追读，全是爽点就失去了魂。

## 二、成长向的章尾钩（在 hit 六种钩型之外新增）

| 钩型 | 写法 | 例句骨架 |
| :--- | :--- | :--- |
| **道德两难钩** | 两个都对的选择，只能选一个 | "举报他，父亲会坐牢；不举报，那十二户人家就拿不回钱。" |
| **真相照见钩** | 真相指向主角自己 | "录像里那个推倒老人的人，穿着他的外套。" |
| **关系裂缝钩** | 重要关系突然出现裂痕 | "她把钥匙放在桌上：'你变了。'" |
| **自我怀疑钩** | 主角第一次怀疑自己的信念 | "他赢了。可他突然想不起来，自己为什么要赢。" |
| **代价降临钩** | 选择的代价在章尾到来 | "电话响了，是医院。" |

## 三、单章四段（成长向版本）

| 区段 | 占比 | 任务 |
| :--- | :--- | :--- |
| **承钩** | 0-15% | 接住上章钩子，不回顾 |
| **事上磨练** | 15-60% | 外部事件施压，逼主角用旧信念应对 |
| **选择时刻** | 60-85% | 一个具体的、有代价的选择（或旧信念下的爽点兑现） |
| **余味 + 新钩** | 85-100% | 一个具体的意象或动作留住余味（不总结），然后抛出新钩 |

**余味写法**：用物件、动作、环境声结束情感段落，而不是用感悟。例如：他把那枚旧硬币放回口袋，没有扔。

## 四、黄金三章的"内在裂缝"

成长向的第一章入口仍然是**欲望或危机**，但必须同时埋下一道"内在裂缝"：

- 主角做了一个有点不对劲、但读者此刻能理解的选择。
- 或者一个小细节暗示他的错误信念（例如他从不让别人帮自己提东西）。
- 读者此刻不必察觉，回头看时会发现"原来从第一章就开始了"。

自检：hit 的三章自检表全部通过 + 以下两项：
- [ ] 第 1-3 章埋下了至少一道内在裂缝，且没有点破
- [ ] 前三章没有任何一句"道理"
