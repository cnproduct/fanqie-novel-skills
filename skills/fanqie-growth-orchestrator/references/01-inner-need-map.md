# 01 欲望 → 需要转化地图（Inner Need Map）

> 每一种表层欲望背后，都有一个更深的需要。爆款满足欲望；精神食粮回应需要。
> 写法上，**先给欲望（入口），再照见需要（出口）**。

## 一、八大欲望的深层需要

| 表层欲望（入口） | 深层需要（出口） | 成长命题（示例） | 常见错误信念 | 觉醒场景骨架 |
| :--- | :--- | :--- | :--- | :--- |
| **变强 / 掌控** | 被自己认可、内在安定 | 真正的力量是能掌控自己，而不是掌控别人 | "只要足够强，就不会再受伤" | 变强后仍然失去重要的人，发现力量解决不了的事 |
| **被看见 / 打脸** | 尊严来自内在，不需要观众 | 不需要赢给所有人看，也能站得笔直 | "别人认可我，我才有价值" | 赢了所有人的那一刻，发现想被看见的那个人并不在场 |
| **暴富 / 安全感** | 真正的安全来自关系与能力 | 钱能买来安全，买不来安心 | "有钱就不会再被抛弃" | 钱解决了危机，却解决不了家人之间的隔阂 |
| **复仇 / 公平** | 正义而非私怨；放下而非遗忘 | 让恶人付出代价，但不让自己变成恶人 | "我的痛苦只有他的痛苦能抵消" | 复仇成功后的空洞，选择交给规则而不是私刑 |
| **被偏爱** | 自我接纳，以及爱人的能力 | 先学会爱自己，才能不把爱当救命稻草 | "只有被选择，我才值得存在" | 主角第一次为自己做选择，而不是等别人选择 |
| **重来 / 逃离** | 承担与弥补，而非抹去 | 重活一次的意义不是逃开错误，而是学会承担 | "如果当初……就好了" | 重生后发现悲剧根源在自己，必须面对而不是绕开 |
| **掌握秘密** | 看清真相，包括看清自己 | 最难揭开的秘密在自己心里 | "真相只在外面" | 层层揭秘之后，最后的真相指向主角自己 |
| **归属 / 守护** | 成为能给出归属的人 | 家不是找到的，是建起来的 | "我不配拥有家" | 从被收留的人变成收留别人的人 |

## 二、题材适配速查

| 题材 | 天然的成长母题 | 番茄化入口 |
| :--- | :--- | :--- |
| 修仙 / 玄幻 | 修心胜于修力、道心、执念与放下 | 废柴逆袭、宗门打脸（外线照常） |
| 重生 / 年代 | 承担、弥补、与父母和解 | 重生改命、年代致富 |
| 都市职场 | 自我价值、边界感、不被异化 | 职场逆袭、反 PUA |
| 家庭 / 现实 | 原生家庭、代际和解、自我接纳 | 断亲、搞事业、清醒大女主 |
| 悬疑 / 刑侦 | 罪与罚、善恶边界、真相的代价 | 规则怪谈、身份谜团 |
| 历史 / 人物 | 知行合一、在时代里做选择 | 穿越、权谋 |
| 科幻 / 末世 | 人性的底线、文明与个体 | 囤货、异能、基建 |

## 三、心灵痛点雷达（G1）

**数据来源**：番茄书评区与段评的高赞评论、社交平台热议话题、公开调查报告（注明来源与日期）。只记录公开可见内容，不收集个人信息。

**整理格式**：

| 痛点（读者原话摘录或概括） | 人群 | 背后的错误信念 | 对应深层需要 | 可承载的题材 |
| :--- | :--- | :--- | :--- | :--- |
| "努力了也没用" | 职场青年 | 价值 = 结果 | 自我价值的内在锚点 | 职场 / 修仙 |

**判断标准**：痛点越普遍、越难说出口、越少被认真回应，越有写的价值。
