# 05 良知标尺：精神价值审计（Conscience Audit）

> 追读力决定读者会不会读下去；精神价值决定读者读完后有没有变得更好一点。两者都要。

## 一、精神价值八维（每项 1-5 分）

| 维度 | 核心问题 | 5 分标准 |
| :--- | :--- | :--- |
| **真实性** | 困境和人物反应是否像真实的人？ | 读者会觉得"我也遇到过" |
| **代价** | 成长是否付出了不可轻易撤销的代价？ | 代价具体、持续、影响后续剧情 |
| **主动选择** | 转变来自主角自己的选择，还是来自外力和巧合？ | 关键转折都是主角在两难中自己选的 |
| **反命题强度** | 对手和诱惑是否有说服力？ | 读者有一瞬间觉得"对手说的也有道理" |
| **人物尊严** | 包括反派在内，是否被当作人来写？ | 反派有来历；配角不是工具 |
| **不说教** | 主题是否由行动证明？ | 全章没有一句作者在讲道理 |
| **余味** | 读完是否有东西留在心里？ | 有一个意象或选择让人回味 |
| **正向牵引** | 读完是否让人更愿意善待自己和他人、更有勇气面对生活？ | 不贩卖焦虑和仇恨，给出可能性而不是标准答案 |

**精神价值评级**：S（≥ 36）/ A（30-35）/ B（24-29）/ C（< 24 或触碰红线或有说教红灯）

## 二、红线（任一项出现，精神价值轴直接判 C）

1. **美化暴力与私刑**：把以暴制暴写成正义的唯一出路。
2. **美化操控**：把 PUA、情感控制、跟踪写成深情。
3. **物化**：把人（尤其是女性、弱者）写成奖励或工具。
4. **群体仇恨**：煽动对某一类人群的仇恨或歧视。
5. **贩卖焦虑**：把成功等同于人的价值，用"不努力就完了"制造恐慌。
6. **伪成长 / 成功学**：成长的唯一标志是变得更有钱、更有权。
7. **道德优越感**：主角觉醒后俯视、审判他人。

## 三、双轴判定（G7 闸口）

| 追读力（hit 审计） \ 精神价值 | S / A | B | C |
| :--- | :--- | :--- | :--- |
| **S / A** | 可发布（理想） | 可发布，下一轮加强魂 | 不可发布：改魂 |
| **B** | 可发布，下一轮加强钩子 | 修改后复审 | 不可发布 |
| **C** | 不可发布：改钩子与节奏 | 不可发布 | 重写 |

## 四、读者回响复盘（G8）

从评论区（公开内容）整理：

| 反馈类型 | 例子 | 说明 |
| :--- | :--- | :--- |
| **共鸣** | "我也是这样""看哭了" | 真实性成功 |
| **反思** | "我好像也一直在讨好别人" | 镜子起作用了 |
| **被说教感** | "作者又在讲道理""好鸡汤" | 去说教失败，回到第四章 |
| **憋屈 / 弃书** | "太压抑了""主角太圣母" | 追读力失败，回到 hit 毒点清单 |
| **争论** | 读者为某个选择吵起来 | 反命题强度成功，好现象 |

**健康信号**：共鸣、反思、争论类评论占比上升，被说教感类评论少于弃书类评论。
