# 02 成长弧：迷 → 觉 → 行 → 合（Growth Arc）

> 借王阳明"知行合一、事上磨练"的思路：觉醒不是想通，而是在事情里一次次被磨出来的。

## 一、四阶成长弧

| 阶段 | 内在状态 | 外在表现 | 篇幅（单卷参考） | 关键场景 |
| :--- | :--- | :--- | :--- | :--- |
| **迷** | 被错误信念驱动，以为自己是对的 | 追逐表层欲望，并且常常得到（爽点） | 0-30% | 错误信念带来"成功"，读者也跟着爽 |
| **觉** | 裂缝出现：得到想要的，却失去更重要的 | 代价降临，旧方法失灵 | 30-55% | **代价场景**：因为旧信念真实地失去 |
| **行** | 尝试新信念，但会倒退 | 用新方式行事，付出更大代价，可能回到老路 | 55-85% | **倒退场景**：压力下重回旧信念，然后再次选择 |
| **合** | 新信念内化成本能 | 在最大考验前，自然地做出与开头相反的选择 | 85-100% | **镜像选择**：与第一卷相似的处境，做出不同选择 |

**长篇结构**：番茄长篇通常 100 万字以上。每卷完成一次"迷觉行合"，全书由多次小循环螺旋上升，最后一卷回应全书的终极命题。

```
卷一：克服"我必须变强"     → 学会"强是为了守护"
卷二：克服"我只能靠自己"   → 学会信任与合作
卷三：克服"我必须赢"       → 学会为了正确的事输
终卷：克服"我必须被记住"   → 学会无我地给予
```

## 二、错误信念设计

一个好的错误信念必须满足：

1. **有来历**：来自一个具体的创伤场景（Ghost），可以在正文里闪回一次。
2. **曾经有用**：这个信念曾经保护过主角，所以他不愿意放下。
3. **可被演出来**：能转化为具体的行为选择，而不是心理描写。
4. **会伤人**：会让主角伤害自己或身边的人。

| 不好的错误信念 | 好的错误信念 |
| :--- | :--- |
| "他很自卑" | "只要我先拒绝别人，就不会被别人拒绝"（于是他推开每一个靠近的人） |
| "她不懂爱" | "爱就是付出，付出得不够就会被抛弃"（于是她讨好到失去自己） |

## 三、代价的五种类型

| 类型 | 例子 |
| :--- | :--- |
| 关系 | 朋友离开、亲人失望、爱人受伤 |
| 自我 | 变成自己曾经讨厌的人 |
| 机会 | 因为旧信念错过真正重要的东西 |
| 无辜者 | 别人为主角的选择买单（最痛，慎用） |
| 力量 | 金手指失效或反噬 |

**代价必须真实**：不能下一章就全部复原，否则读者会认为成长是假的。

## 四、镜像人物

每个主角至少要有一个**镜像人物**：和主角有相同的创伤，却选择了另一条路。

- **黑镜**：继续被错误信念驱动，最终毁灭或堕落（展示主角可能的结局）。
- **白镜**：先一步走出来的人（不能变成说教的导师，只能用行动示范，并且有自己的缺陷）。

## 五、双线对位

每一个觉点必须挂在一个外部事件上。没有外部事件的觉醒就是说教。

| 章 | 外部爽点线（事件） | 内部觉点线（信念变化） | 代价 |
| :- | :--- | :--- | :--- |
| 15 | 主角当众击败宗门天才 | 迷：信念被强化——"强就有尊严" | — |
| 28 | 主角为夺资源抛下同伴 | 觉：裂缝——同伴重伤，他第一次犹豫 | 关系 |
| 41 | 再次面临资源与同伴二选一 | 行：选了同伴，失去晋升机会 | 机会 |
| 60 | 卷末大战，以守护者身份获胜 | 合：新信念成为本能 | — |
