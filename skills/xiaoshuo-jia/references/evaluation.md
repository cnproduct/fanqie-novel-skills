# 阶段③ 评估 — 质量评估与六维评分

评估必须**量化优先、印象次之**。先用脚本跑硬指标，再附定性评述。本文件给两套可交付评估的框架与 rubric。

## 一、质量评估报告（综合版，100分制综合定调）

### 1.1 硬指标（脚本产出，必须真实可复现）

```bash
python scripts/wordcount_check.py novels/[书名]/ --volumes "1-15,16-35,36-65,66-85,86-100"
python scripts/hook_rotation_check.py novels/[书名]/
```

报告必须包含：
- **字数纪律**：章数、均值、中位数、最小/最大、标准差、超标章（<2200 或 >2800）列表。健康线：均值 2400–2700、标准差 < 100、超标章为空或仅 1 章微超（可忽略）。
- **钩子分布**：A/B/C/D/收 各自计数。健康线：四型均衡、B 略多、收仅终章 1 处。
- **5章单元轮换合规率**：统计相邻同型单元数。健康线：100%（或仅 1–2 处且为卷末双爆点）。
- **分卷均字均衡**：五卷均值极差应 < 150。

### 1.2 定性评述（结合抽样阅读，禁止空谈）

至少直读 4 章关键样本（开篇、中段反杀、身份揭秘、结局），覆盖五幕。维度：
- 文笔与叙事（对话是否个性、描写是否具体）
- 结构/节奏（钩子是否承上启下、单元是否压-扬-爆）
- 伏笔回收（是否开篇即埋、跨章呼应、终局闭环）
- 爽点密度（打脸/逆袭/掌权是否到位）
- 无CP纪律（全书零感情线，关系定性清晰）

### 1.3 可优化点清单（按严重程度排序）

每条标注：是否"校样级"（一行级修正，1 小时内可清零）、具体文件与行号、修改建议。

### 1.4 报告模板

```
# 《[书名]》质量评估报告

## 综合评分：X.X / 10

### 一、字数纪律（脚本核验）
[粘贴 wordcount_check 输出]

### 二、节奏与钩子
[钩子分布 + 轮换合规率 + 假阳性说明（若有）]

### 三、文笔与叙事（样本评析）
[4章样本要点]

### 四、伏笔回收 / 爽点 / 无CP纪律
[要点]

### 五、分卷均衡度
[五卷均字]

### 六、可优化点（按严重度）
1. [校样级] 第XX章超字 → 删X字
2. [轻] 第XX章叙述者代讲 → 改具体因果
……

### 七、一句话定调
[全书是否可投递]
```

## 二、六维量化评分（对标 novel-evaluator，100分）

| 维度 | 满分 | 评估要点 | 典型扣分项 |
|------|------|---------|-----------|
| 情节架构 | 25 | 开局钩子、主线清晰度、伏笔铺设与回收、节奏（压-扬-爆）、结局闭环 | 伏笔未收、中段拖沓、结局仓促 |
| 人物塑造 | 20 | 主角动机清晰、配角有弧光（非工具人）、成长可见、关系合理 | 功能性偏强、脸谱化、动机模糊 |
| 文笔质量 | 15 | 描写具体、对话个性、节奏（长短句）、去AI味程度 | 套路表达、tell 重于 show、陈词 |
| 世界观设定 | 15 | 设定自洽、有独特机制、细节纹理 | 设定空洞、只有一极（如只写朝堂无市井） |
| 情感共鸣 | 15 | 人物困境可感、爽点到位、结尾余韵 | 情绪造假、爽点疲软 |
| 创新性 | 10 | 题材/结构/人设有新意、非纯套路 | 高度同质化 |

### 2.1 去AI味扫描（作为文笔维度证据）

用 humanizer 自己的禁用词/结构清单对全本做**只读扫描**（见 `references/deai.md`），在报告中给出：
- 通用禁用词（综上所述/值得注意的是/毋庸置疑/随着…发展/意义重大 等）命中数（健康：≈0）
- "带着X/不是X而是Y/这一刻/X知道/一丝"等标记的**误判率**（小说里多为合法修辞，需逐处判断是否真杂草）
- 全本重复 crutch 词（如"心头一震"出现 N 次且均表同一反应）

## 三、分级建议

- **S 级（≥90）**：出版/影视改编潜力，仅校样级微瑕。
- **A 级（80–89）**：平台签约级，1–2 处结构性可优化。
- **B 级（70–79）**：可读，需补强人物或节奏。
- **<70**：建议回炉重写中段或重排钩子。
