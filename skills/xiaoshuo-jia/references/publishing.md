# 阶段⑤ 上架发布 — 交付读者稿

本文件定义从工程文件到平台发布物料的四件套产出。注意：**AI 无法代你登录平台点"发布"**（需账号+实名认证+后台操作），本阶段产出的是"复制粘贴 + 走流程"即可上架的完整物料。

## 一、干净发布版（剥离全部写作元数据）

章节文件里的 `## 本章概要`、`### 章节备注` 是工程笔记，**绝不进读者稿**。

```bash
python scripts/strip_metadata.py novels/[书名]/ novels/[书名]/发布版/
```

- 只抽取 `## 正文` 到 `---` 之间的正文。
- 输出 `001-标题.txt` … `100-标题.txt`，带前导零、按章序排列。
- 出版前复核：单章最小字数应远超平台单章红线（如书旗约 1000 字），通常无需拆章。

## 二、平台简介（派 copywriter）

走团队流程派给文案组成员（copywriter），要求：

1. **主简介正文**：200–360 字，第一人称或强反差开场，前 1–3 句直接抛爆点/悬念，突出核心爽感（如"弃女逆袭/掌权/打脸/无CP大女主"），结尾留钩子。
2. **一句话吸睛版**：≤50 字，强反差或悬念，可作简介首行/吸睛位。
3. 主理人收到成稿后**必须脚本核验字数**再落盘。

> 书旗偏好：开篇抛"弃子→戴紫冠"式反差、信息密度高、突出无CP事业线。不同平台（番茄/起点）口味不同，按需调整。

## 三、上架信息单（派 copywriter）

产出一份结构化信息单，便于直接复制进建书表单：

```
# 《[书名]》[平台]上架信息单

## 一、书名建议
- 主推：《[书名]》（说明…）
- 备选1：…（说明…）

## 二、分类归属
- 主分类：…（如 古代言情）
- 子分类：…（如 权谋 / 宫斗宅斗）
- 理由：…

## 三、精准标签（6–8个，覆盖四维度）
人设 / 题材 / 爽点 / 属性
例：大女主 / 孤女逆袭 / 智谋女主 / 朝堂权谋 / 宅斗 / 打脸爽文 / 无CP / 事业线

## 四、笔名取向
- 笔名1（注解…）
- 笔名2（注解…）
- 笔名3（注解…）
```

## 四、封面（派 image-creator）

走团队流程派给图片组成员（image-creator），规格：

- **竖版 2:3**（如 832×1216 或 800×1200），适配书旗/番茄封面位。
- **风格**：古风水墨/工笔 + 电影感打光，暗色背景配金/朱红点缀，高级感、不二次元卡通。
- **产出 2–3 版**：至少 2 张**纯净画面版**（无多余文字，留白充足可叠加书名/笔名）+ 1 张**带字版**（用文字渲染能力把书名以古风字体嵌入顶部作备选）。
- **风格锚定一致**：同一主角形象、同一色调体系，仅构图/焦点/意象不同。

> 提示：AI 生图右下角常带"图片由AI生成"水印，上传前在平台封面编辑器裁掉，或用 ImageEdit 二次处理。推荐"纯净底图 + 带字版书名区域叠加"得最优成品。

## 五、用户实际后台操作（告知用户）

1. 登录 `[平台]作家专区` → 身份证实名认证
2. 新建作品：填书名、选分类、贴简介（吸睛版可放首行）、传封面
3. 章节发布：从 `发布版/` 按 `001-…txt` 顺序粘贴/批量导入，**建议首发 3–5 章**起更
4. 提交审核（1–3 工作日）→ 上架 → 达字数/数据后等编辑邀约签约

> 平台规则会变，具体门槛以用户登录后后台提示为准。
