# 阶段① 规划 — 详细方法论

本文件定义《小说家》技能的项目结构、五幕结构、钩子轮换系统与章节格式。所有生成阶段都依赖这里的约定。

## 一、项目目录树

```
novels/[书名]/
├── 00-大纲.md              # 总纲：设定 + 五幕规划 + 进度看板 + 章节摘要
├── 02-情绪曲线.md           # 钩子追踪表（章号 × 钩子类型 × 备注）
├── 第01章-毒酒.md           # 章节文件（带元数据）
├── 第02章-…….md
├── ……
├── 第100章-敬该敬的人.md
├── 节奏报告-01-05章.md       # 每5章一份节奏报告
├── 质量评估报告.md           # 阶段③产出
├── 小说评分报告.md           # 阶段③六维评分
├── 发布版/                  # 阶段⑤剥离后的读者稿
│   ├── 001-毒酒.txt
│   └── ……
├── 上架信息单.md             # 阶段⑤书名/分类/标签/笔名
├── 书旗版简介.md            # 阶段⑤平台简介
└── 书旗封面/                # 阶段⑤封面图
```

> 文件名带前导零（`第01章` 不是 `第1章`），便于自然排序。

## 二、五幕结构

把全书切成 5 个卷，每卷有明确功能与情绪基调。以 100 章为例：

| 卷 | 章区间 | 功能 | 情绪基调 |
|----|--------|------|---------|
| 一·弃子 | 1–15 | 死局→觉醒→离场 | 压抑→破局 |
| 二·入朝 | 16–35 | 初入权力场，小胜积累 | 试探→立威 |
| 三·掌权 | 36–65 | 掌印，正面扳倒一方势力 | 高燃→反杀 |
| 四·对峙 | 66–85 | 与终极反派短兵相接 | 紧绷→绝境 |
| 五·天下 | 86–100 | 收束、立制、闭环 | 释然→留白 |

**分卷字数应均衡**（极差控制在 ±150 字内），终卷可略降速作良性留白。

## 三、钩子轮换系统（核心纪律）

五种钩子类型，每章必须择一标注：

| 代号 | 类型 | 含义 | 例 |
|------|------|------|----|
| A | 信息差 | 读者/主角知道别人不知道的事 | "他瞒她的，比泄露的更大" |
| B | 危机逼近 | 威胁迫近、命悬一线 | "搜捕已刮到暗窖外" |
| C | 关系转折 | 盟友/敌我关系质变 | "从谋主到同路人" |
| D | 身份揭秘 | 身世/真实身份揭破 | "原来她是镇国公府遗珠" |
| 收 | 收束留白 | 单元/全书收尾的钩子回收 | 终章毒酒盏→祭酒 |

**轮换规则**：每 5 章为一单元，单元内**相邻两章不得同型**。全本统计上 A/B/C/D 应均衡分布（B危机通常略多）。

> 权威源：以**章节文件自身 `## 本章概要` 的"悬念钩子"标注**为准；`02-情绪曲线.md` 的追踪表必须与章节标注保持一致，否则会出现"连续同型"的**假阳性误报**。

## 四、章节文件格式

```markdown
# 第XX章-标题

## 本章概要
- 悬念钩子：[A信息差 / B危机逼近 / C关系转折 / D身份揭秘 / 收束]
- 伏笔：[本章程埋下或回收的伏笔，注明"新埋/X章回收"]

## 正文
[正文内容，2200-2800 字，CJK 计]

---

### 章节备注
- 钩子标记：[A/B/C/D/收]
- 伏笔标记：[与上文伏笔对应的追踪注释]
- 字数核验：[如 2628]
```

完整起稿骨架见 `templates/chapter-template.md`。

## 五、大纲与情绪曲线模板

- `00-大纲.md`：设定（世界观/人设/核心冲突）→ 五幕规划（每幕目标+关键节点）→ 进度看板（TODO）→ 章节摘要（每章 100–200 字）。
- `02-情绪曲线.md`：表格逐章记录 `章号 | 钩子类型 | 钩子内容/备注`，并附"实际钩子使用记录"区块，供 `hook_rotation_check.py` 核对。

模板见 `templates/outline-template.md`。

## 六、人物补强（阶段④用）

当评估发现某角色"功能性偏强/工具人"，按以下规则补强，**严守无CP纪律（不得引入任何感情线）**：

1. **锚定既有道具/线索**：补的笔必须贴着该角色已有的物件或伏笔（如"旧铜镇=父镇纸缺角""梦'庚'字"），不外溢设定。
2. **补"带体温的底色"**：给角色一个私人层面的怕、梦、愧、释然——把抽象表述（"替父还债"）落成具体细节。
3. **跨章递进呼应**：让该弧光在 2–3 章递进（如 第39章"不敢离身" → 第70章"不敢以真名相认旧部" → 第97章"终于把父命接过递出"），形成情感弧光。
4. **字数纪律不变**：补强后单章仍须落在 2200–2800 区间，并同步更新该章 `### 章节备注` 的伏笔标记。
