# 阶段④ 去AI味（适配小说版）

本文件把通用 humanizer 技能改造为**小说专用**的去味流程。核心原则：**不破坏文风、不破坏字数控、不破坏对话**。

## 一、对通用 humanizer 的三条豁免（铁律）

通用 humanizer 为公众号/技术文设计，直接套小说会毁稿。本技能**明令豁免**以下规则：

| 通用规则 | 对小说的影响 | 本技能处理 |
|---------|------------|-----------|
| L1-2 标点禁令（删引号、破折号） | 古言对话/停顿全毁 | **豁免**，引号破折号照常保留 |
| "禁止长句" | 小说需要长短句交替造节奏 | **豁免**，只反对无意义的堆砌 |
| 删所有"很/非常/十分" | 古言里多作合理程度副词 | **不强制**，仅统计占比作参考 |

## 二、只读扫描（第一步，必须）

用 humanizer 自己的高信号清单对全本做扫描，**先量化再判断**，避免"感觉有AI味就通改"的破坏性 churn。重点扫：

1. **套路表达**：深吸一口气 / 嘴角微微上扬 / 眼神变得坚定 / 心中涌起一股暖流 / 无奈地摇了摇头 / 紧紧地握着 / 缓缓地开口 / 眼神一暗 / 心头一酸 / 眼底一暗
2. **通用禁用词**：综上所述 / 值得注意的是 / 不难发现 / 毋庸置疑 / 毫无疑问 / 随着…的发展 / 在…的背景下 / 意义重大 / 影响深远 / 说白了 / 本质上 / 换句话说
3. **结构标记**：带着X（万能状语）/ 不是X而是Y（二元对比）/ 这一刻…（升华）/ X知道…（tell）/ 一丝（泛化量词）

## 三、命中分类（关键：多数命中是误判）

扫描后必须逐类判断是否真杂草，**小说里以下用法是合法修辞，保留**：

| 标记 | 书中典型合法用法 | 判定 |
|------|----------------|------|
| 带着X | "带着颤 / 潮气 / 雪水凉 / 铁甲相磕的细响" | ✅ 具体感官，好文笔 |
| 不是X而是Y | "不是一户部主事的贪，而是一条直通相府的路" | ✅ 剧情揭示 |
| 这一刻… | "这一刻，危机逼近眉睫" | ✅ 场景节拍标记 |
| X知道… | "她知道，弹劾的折子就在路上" | ✅ 第三人称限知标准叙事 |
| 一丝 | "一丝血色 / 凉意 / 慌" | ✅ 具体量词（41 处全为具体感官则保留） |
| 轻轻/微微/淡淡/缓缓/仿佛 | 古言正常笔法 | ✅ 保留（217 处级也正常） |

**真杂草候选（值得逐处复核）**：
- 全本重复的 **crutch 词**（如"心头一震"出现 4+ 次且都表"惊觉"）→ 必收
- 纯"告知认知"的 tell 反应句（"心下了然""心头一震"类）→ 改身体动作
- 叙述者代讲（把角色算计抽象解释给读者）→ 收成具体因果

## 四、精准小批润色（第二步）

只对手工确认的 5–10 处下手，规则：

1. **能改一个词就不改一句**；没问题的尽量留。
2. **crutch 词 → 不同身体反应**：把全本重复的"心头一震"换成 顿指 / 屏息 / 眉心跳 / 袖中握紧 等，既去味又破重复。
3. **tell → show**："心下了然——X"改为动作（"将旧印在袖中又按了按，面上不动声色"）。
4. **叙述者代讲 → 具体因果**：删掉双重抽象说明，只留"背着贪墨名的核账官，那本账便再没人敢接"这种因果。

## 五、禁止动作

- ❌ 全本 100 章通扫式改写（在已干净的文章上做破坏性 churn，还会冲乱字数控与钩子排布）。
- ❌ 删引号/破折号。
- ❌ 为去味牺牲具体意象。

## 六、交付

- 列出**实际落刀清单**（章 / 原句 / 改为），附理由。
- 落刀后必须重跑 `wordcount_check.py` 确认单章仍在区间内。
- 向用户说明：若扫描显示高信号命中 95% 为合法修辞误判，则"去味"实际只需极少数 surgically 收口，强行全改反而是破坏。

> 若用户坚持全本通扫，先出**巡检报告**让用户审阅再决定，不盲目执行。
