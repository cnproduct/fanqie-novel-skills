# 网文文风诊断 + 投稿双轨评分

对网络小说/网文文本做**两件事**：

1. **检测半区**：跑 `scripts/style_scan.py`，用数据回答"我的文字像不像机器写的、AI 味在哪"；
2. **评分半区**：按 `references/tomato-evaluator.md` 双轨体系，回答"能不能签约、能签多少、怎么改"。

**本技能只诊断+评分，不改写**——改写交给 `novel-deai-rewriter` 技能。

> 本技能基于公开的 AI 文本检测原理（困惑度 + 爆发度 + 统计指纹）与网文平台的公开质量规则，做**本地代理式诊断**——不是任何平台的官方工具，结果仅供作者自检参考（详见 `references/style-principles.md`）。

核心价值：**一次调用，拿到"客观检测数据 + 文学六维 + 平台六维 + 投稿决策 + 行动清单"的完整报告**——不再是孤零零一个 AIGC 值，也不是 LLM 凭感觉打分。

## 何时使用

- 用户提交一段/一篇小说，问"AI 味重不重""文字像不像机器写的" → 跑检测半区
- 用户问"这篇能不能签约、有没有流量、值不值得投" → 检测 + 评分双半区
- 投稿前自检：跑一遍扫描看 AIGC 值落哪一档，再看双轨分够不够投
- 用户问"我改完之后 AI 味降了没有"：改前改后各跑一遍对比
- 用户想了解 AI 检测原理或某个指标的含义

## 使用流程

### 步骤 1：取得文本并落盘

用户提交的文本可能是粘贴在对话里的，也可能是文件。若是粘贴文本且较长，先写入一个临时 `.md`/`.txt` 文件（章节标题用"第X章"格式便于逐章分析）。

### 步骤 2：运行扫描器（检测半区，客观）

```bash
python scripts/style_scan.py <文件路径> [--json 输出.json]
```

- 无章节标题也能跑，但会当作单章，章字数 CV 退化为 N/A，爆发度权重下降。建议保留"第X章"标题。
- 输出报告包含：总 AIGC 特征值、六维度得分、各指标原始值、逐章明细、高密度锚点段落。

### 步骤 3：通读全文，完成双轨评分（评分半区，主观）

按 `references/tomato-evaluator.md` 完成：

1. 第一轨文学六维（情节/人物/文笔/世界观/情感/创新）；
2. 红线扫描（第二轨第 1 项，命中即置顶警告）；
3. 第二轨平台六维——其中 **AI 痕迹维度（15 分）必须引用步骤 2 的脚本数据**，按 `references/scoring-rubric.md` 第六节换算（AIGC 值换算 7 分 + 六维度报警 4 分 + 分布形态 4 分），**不允许退回"感觉像 AI"**；
4. 查合轨决策矩阵，输出投稿建议。

### 步骤 4：解读 + 定位 + 建议

- **风险分档**（`scoring-rubric.md` 第一节）：
  - < 0.40 人工特征：告知安全；
  - 0.40–0.70 疑似 AI：指出哪些维度/章节报警，给"改什么"建议；
  - ≥ 0.70 高度疑似：提示判罚风险，建议先跑 `novel-deai-rewriter`。
- **定位**：用"每章明细"找句长 CV 骤降或黑名单密度异常的章节；用"高密度锚点段落"指出命中最多的段落，建议优先改。
- **行动清单**：报告末尾给可执行清单（改哪一章、换哪个书名、前置哪个爽点）。
- 若需改写，把结论和定位交给 `novel-deai-rewriter` 技能执行（本技能到此为止）。

## 关键原则

1. **报告是"写作风格分析器 + 投稿参谋"，不是平台判决书**。本地代理 ≠ 平台真实检测，结果仅供自检参考，不保证与平台结果一致。
2. **检测的是"低质 AI 文"，不是"用没用 AI"**。平台合规红线是"AI 不能当正文主力"；大纲、查资料、校对是允许的。不恐吓作者，也不教作者"如何规避检测作弊"。
3. **客观半区不可跳过**：只要环境能跑脚本，AI 痕迹维度就必须用 `style_scan.py` 真实数据。
4. **优先信任爆发度**（句长/段长/章字数 CV），它最可靠、最难伪装；情感扁平度主观性最强、误报风险最高。
5. **两轨独立打分**：文学分高不抬平台分，反之亦然；红线命中平台分不超 40。

## 与 novel-deai-rewriter 的分工

| 场景 | 用哪个技能 |
|---|---|
| 想知道文本 AI 味重不重、在哪 | **本技能**（检测半区） |
| 想知道能不能签约、怎么改 | **本技能**（评分半区） |
| 要把 AI 味重的文本改得不像 AI | novel-deai-rewriter |
| 改完验证有没有降下来 | 本技能（重跑对比） |

典型闭环：检测 + 评分 →（有问题）→ novel-deai-rewriter 改写 → 重跑本技能验证。
