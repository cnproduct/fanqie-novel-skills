# fanqie-audit-refiner (番茄小说专业审校与去AI味精修引擎)

面向番茄小说全流程创作的机械级审校、自然语言去 AI 味改写与官方机审风控闭环子技能。

## 核心功能
1. **硬禁项彻底查杀**：自动替换消除全部破折号 `——`、`不是…而是…` 翻案对比句、提示性冒号与口头路标。
2. **语境黑话纠偏**：把现代互联网宣传黑话（赛道、生态、赋能、闭环）还原为符合年代与小说真实场景的实体词（跑道、花园厂房、助推、造出）。
3. **番茄词库双雷达**：联动 `ai_cliche.txt`（神态套话/旁白腔）与 `preachy.txt`（反导师说教），执行全自动查杀与改写。
4. **官方机审风控拦截**：过滤真实证券代码、外链域名、敏感高职全称与连载完本标记，杜绝后台“审核不通过”拦截。
5. **移动端律动分句**：自动拆分超过 45 字的长句，保持单句长度变异系数 $CV \ge 0.35$。
6. **无缝对接发布器**：精修达标（`clean (0)`）后一键导出纯文本至 `05-fanqie-upload/`，直接交付 `fanqie-auto-publisher` 批量上传。
