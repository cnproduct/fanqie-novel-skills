# 01 欲望靶点地图（Desire Map）

> 爆款不是写"好故事"，而是写"读者此刻最想要、现实中得不到的东西"。先找靶点，再找题材。

## 一、八大欲望靶点

| # | 欲望靶点 | 现实痛点 | 幻想补偿 | 典型标签（番茄常见） | 兑现形式 | 过量风险 |
| :- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | **掌控 / 力量** | 无力感、被规则支配 | 变强、无敌、掌控局面 | 系统、无敌流、全民转职、修仙 | 升级、突破、碾压 | 战力通胀、无敌即无聊 |
| 2 | **尊严 / 被看见** | 被轻视、被低估 | 打脸、身份揭晓、扮猪吃虎 | 赘婿、战神、真千金、马甲 | 当众反转、众人震惊 | 打脸套路化、反派降智 |
| 3 | **财富 / 安全感** | 经济焦虑、不确定性 | 暴富、囤货、稳定 | 神豪、末世囤货、年代经商 | 资产增长、物资清单 | 数字堆砌无情感 |
| 4 | **公平 / 复仇** | 不公、委屈无处申 | 恶有恶报、加倍奉还 | 重生复仇、追妻火葬场、退婚流 | 反派付出代价 | 憋屈过长导致弃书 |
| 5 | **被偏爱** | 不被珍视、孤独 | 被坚定选择、全员宠爱 | 甜宠、团宠、先婚后爱 | 偏爱细节、护短 | 女主工具化、无脑虐 |
| 6 | **重来 / 逃离** | 遗憾、后悔、困局 | 重生、穿越、另一种人生 | 重生、穿书、年代、快穿 | 规避前世错误、提前布局 | 先知优势用完后乏力 |
| 7 | **好奇 / 掌握秘密** | 信息不对称 | 我知道别人不知道的 | 规则怪谈、悬疑、鉴宝、读心 | 信息差反杀、揭秘 | 设定自相矛盾 |
| 8 | **归属 / 守护** | 疏离、无依 | 有家、有团队、能保护他人 | 种田、基建、家族、宗门 | 建设成果、家人安好 | 节奏过慢 |

**组合规律**：爆款通常是 **1 个主靶点 + 1~2 个副靶点**。例如：重生复仇 = 重来（主）+ 公平 + 尊严。

## 二、男频 / 女频靶点偏好（经验倾向，非绝对）

- **男频**：掌控、尊严、财富、好奇为主；兑现节奏更快，数值化反馈（等级、资产、战力）更受欢迎。
- **女频**：被偏爱、公平、尊严、重来为主；近期"清醒大女主、反内耗、搞事业"上升，单纯虐恋下降。

## 三、番茄读者常见毒点（弃书高发）

1. 主角圣母、以德报怨、反复放过反派
2. 憋屈超过 2 章仍无反击信号
3. 金手指无限制，或主角长期不用金手指
4. 反派降智到读者不信
5. 开篇大段世界观、背景、回忆
6. 感情线拖沓、误会靠"不长嘴"维持
7. 女主（或男主）工具化、只为衬托
8. 前后设定矛盾、战力崩坏
9. 断更或章节注水（大量重复描写）

## 四、选题评分卡（每项 1-5 分）

| 维度 | 问题 | 分数 |
| :--- | :--- | :- |
| 欲望强度 | 读者看到书名+简介，会不会立刻产生"我想要这个"？ | |
| 新鲜度 | 与榜单 Top 30 的同质化程度如何？有没有一个"新组合"？ | |
| 可持续性 | 这个设定能否撑 100 万字以上（升级空间、地图扩展、反派梯队）？ | |
| 开篇爆点 | 第一章能否在 300 字内抛出核心冲突？ | |
| 合规风险 | 是否触碰 [05-fanqie-compliance.md](05-fanqie-compliance.md) 红线？（5=无风险） | |

**≥ 20 分**：推荐立项；**15-19**：需加强短板；**< 15**：放弃或重组。
