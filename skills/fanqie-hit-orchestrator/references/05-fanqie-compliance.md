# 05 番茄合规红线（Compliance）

> 本文件是创作自检用的**通用网络文学合规提示**，不是番茄官方规则。
> 平台规则会更新，以番茄作家后台最新《内容规范》和公告为准。短剧侧补充见 `../../short-drama/references/compliance-checklist.md`。

## 一、硬红线（出现即不可发布）

| 类别 | 说明 |
| :--- | :--- |
| 政治与历史 | 歪曲历史、恶搞英烈、影射现实政治人物与事件 |
| 色情 | 露骨性描写、性暗示擦边、涉及未成年人的任何性相关内容 |
| 暴力 | 血腥细节特写、虐杀过程描写、宣扬以暴制暴 |
| 违法犯罪 | 赌博、毒品、诈骗的可操作方法描写；美化犯罪 |
| 歧视与仇恨 | 针对民族、地域、性别、残障等群体的侮辱 |
| 封建迷信 | 宣扬迷信可以真实改命、骗财（玄幻设定不等于宣扬迷信） |
| 未成年人保护 | 未成年人恋爱擦边、不良行为示范 |
| 自伤自杀 | 方法细节描写、美化自杀 |

## 二、软风险（需要处理的写法）

| 风险写法 | 安全替换 |
| :--- | :--- |
| 血腥打斗特写 | 写结果和反应，不写伤口细节 |
| 主角违法报复 | 改为合法手段、商业竞争、证据反制、规则内碾压 |
| 黑帮/赌场题材 | 主角站在对立面，或改为合法行业 |
| 亲密场景 | 拉灯、转场、留白 |
| 真实品牌/机构/人物 | 虚构名称 |
| 现实中的单位作为反派 | 虚构机构或个人行为，不指向群体 |

## 三、审计时的执行方式

1. 跑 `scripts/text_lint.ps1`，查看"风险词"命中（只是提醒，需要人工判断语境）。
2. 按上表逐条复核本章。
3. 有硬红线：**评级直接为 C**，必须改写后重审。
4. 软风险：列入审计报告的修改清单。
