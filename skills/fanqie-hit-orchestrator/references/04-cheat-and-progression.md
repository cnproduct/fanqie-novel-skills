# 04 金手指与成长阶梯（Cheat & Progression）

## 一、金手指四要素（缺一不可）

| 要素 | 问题 | 作用 |
| :--- | :--- | :--- |
| **来源** | 从哪来？（系统、重生记忆、血脉、异能、物品） | 合理性 |
| **规则** | 怎么用？触发条件、冷却、限制 | 让读者能"预判爽点" |
| **代价** | 用了失去什么？（寿命、积分、暴露风险、情感） | 制造紧张，防止无敌即无聊 |
| **上限** | 成长到哪一步？分几级？ | 支撑 100 万字的升级空间 |

## 二、成长阶梯设计

```
第一卷（1-60章）   新手期：金手指初显，地图=小城/家族/公司，反派=身边小人
第二卷（61-150章）  上升期：规则拓展，地图=城市/宗门/行业，反派=地区势力
第三卷（151-300章） 爆发期：身份揭晓，地图=全国/大陆，反派=幕后组织
第四卷及以后        巅峰期：终极秘密，地图=世界/位面，反派=终极黑手
```

**每卷必须同时升级三样**：主角能力 · 地图/舞台 · 反派等级。只升能力不升舞台，读者会腻。

## 三、数值面板（适用系统流、修仙、全民转职）

- 面板字段固定，在 `bible.md` 中定义一次，正文复用。
- 每次数值变化同步写进 `state.md`，防止前后矛盾。
- 面板出现频率：关键节点出现，不要每章刷屏。

## 四、反派梯队匹配

每个阶段的反派强度 = 主角当前强度 × 1.2~2 倍（让主角"险胜"而不是"碾压"）。
详细分层见 `../../short-drama/references/villain-design.md`。

| 层级 | 作用 | 处理方式 |
| :--- | :--- | :--- |
| 炮灰 | 提供小爽点 | 1-3 章内解决 |
| 小头目 | 提供中爽点 | 一个小卷内解决 |
| 阶段 Boss | 提供大爽点 | 卷末解决 |
| 幕后黑手 | 贯穿全书的悬念 | 全书后段揭晓 |

## 五、战力崩坏自检

- [ ] 新能力是否让旧反派显得太弱、旧冲突失去意义？
- [ ] 主角是否有"用不了金手指"的合理时刻（制造紧张）？
- [ ] 数值是否只增不减？（适当的失去更有张力）
- [ ] 新地图的规则是否能限制主角旧能力？
