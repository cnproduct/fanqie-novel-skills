# 03 单章引擎与章尾钩（Chapter Engine）

## 一、单章四段结构（2000-3000 字/章，经验值）

| 区段 | 占比 | 任务 |
| :--- | :--- | :--- |
| **承钩** | 0-15% | 立即接住上一章的钩子，不铺垫、不回顾 |
| **加压** | 15-60% | 反派施压 / 困难升级 / 信息差积累，读者情绪往下压 |
| **兑现** | 60-85% | 小爽点：反击、收获、揭秘、被偏爱，读者情绪释放 |
| **新钩** | 85-100% | 抛出新危机或新期待，**在最高点断章** |

## 二、爽点三级节奏

| 级别 | 频率（经验值） | 例子 |
| :--- | :--- | :--- |
| 小爽 | 每章 | 一句话怼回去、拿到小奖励、获得关键信息 |
| 中爽 | 每 3-5 章 | 当众打脸、小境界突破、反派小头目倒下 |
| 大爽 | 每 10-20 章（一个小卷） | 身份大揭晓、大反派阶段性覆灭、地图升级 |

**压抑上限**：连续压抑不超过 2 章；压抑期也要给"反击信号"（主角暗中布局、读者知道的信息差）。

## 三、六种章尾钩

| 钩型 | 写法 | 例句骨架 |
| :--- | :--- | :--- |
| **危机悬停** | 危险降临的瞬间断章 | "刀锋已经贴上了他的喉咙。" |
| **身份将揭** | 真相差一步揭开 | "他摘下面具的那一刻，全场死寂。" |
| **奖励预告** | 金手指给出诱人奖励 | "【任务完成，奖励即将发放：……】" |
| **反派反扑** | 刚赢就出现更大的敌人 | "门外，停着十辆黑色的车。" |
| **信息炸弹** | 一句话颠覆认知 | "你父亲，没有死。" |
| **选择困境** | 两难抉择摆在面前 | "救她，还是救他，你只有十秒。" |

**禁止的结尾**：总结、感悟、"这一天就这样过去了"、无悬念的入睡。

## 四、番茄文风规范

- **段落短**：一段 1-3 句，手机屏 ≤ 3 行；长段落拆开。
- **对话推动**：对话占比通常 30%-60%，用对话交代信息，而不是旁白。
- **白描直给**：写动作和结果，少写形容词和心理分析。
- **情绪外化**：用反应写情绪（摔杯子、沉默、笑出声），不用"他感到愤怒"。
- **信息即时**：读者需要的信息在需要时给，不提前铺。

## 五、写完一章后必须更新 state.md

- 最新章号与一句话摘要
- 主角数值/资产/关系变化
- 新埋伏笔（编号）与已回收伏笔
- 下一章要接的钩子
